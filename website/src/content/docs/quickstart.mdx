## Download / 下载

<p data-lang="en"><a href="https://github.com/Infinimesh-ai/InfiniShell-Desktop/releases/latest">GitHub Releases</a> provides a macOS Apple Silicon DMG, a Windows x64 installer, and Linux x86_64 packages. macOS Intel archives are SSH extensions only. Read the release notes for signing status, known limits and verification scope. The steps below are for building from source.</p>
<p data-lang="zh"><a href="https://github.com/Infinimesh-ai/InfiniShell-Desktop/releases/latest">GitHub Releases</a> 提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Linux x86_64 软件包。macOS Intel 归档仅用于 SSH 扩展。签名状态、已知限制与验收范围以对应版本发布说明为准。以下步骤用于源码构建。</p>

## Prerequisites

<p data-lang="en">All builds need: a working <code>git</code>, a Rust toolchain (<code>rustup</code>), and the platform's native build tools listed below. The repo ships a <code>script/bootstrap</code> entrypoint that installs the right set for your OS.</p>
<p data-lang="zh">所有平台均需准备:可用的 <code>git</code>、Rust 工具链(<code>rustup</code>),以及下文列出的本机构建工具。仓库提供 <code>script/bootstrap</code> 入口脚本,会根据当前操作系统自动安装对应依赖。</p>

## 2. Install build dependencies

<p data-lang="en">Pick your platform. The bootstrap script delegates to <code>script/macos/bootstrap</code>, <code>script/linux/bootstrap</code>, or <code>script/windows/bootstrap.ps1</code> automatically.</p>
<p data-lang="zh">请根据当前平台选择对应步骤。<code>script/bootstrap</code> 会根据操作系统自动调用 <code>script/macos/bootstrap</code>、<code>script/linux/bootstrap</code> 或 <code>script/windows/bootstrap.ps1</code>。</p>

## 3. Build & run

<p data-lang="en">InfiniShell's community application binary is <code>infinishell</code>. The workspace also retains the <code>warp</code> library name for upstream source compatibility; it is not a separate community application binary.</p>
<p data-lang="zh">InfiniShell 的社区应用二进制名为 <code>infinishell</code>。工作区仍为上游源码兼容保留 <code>warp</code> 库名称,但它不是另一个社区应用二进制。</p>

## 4. Configure a provider

<p data-lang="en">After launch, open <code>Settings → AI → Providers</code> and configure a provider endpoint. Provider metadata is saved in <code>settings.toml</code>; API keys are stored in the OS keychain and sent to the endpoint you configure when making requests.</p>
<p data-lang="zh">启动后,打开 <code>设置 → AI → 提供商</code> 并配置提供商端点。提供商元数据保存在 <code>settings.toml</code>;API 密钥保存在系统密钥库中,请求时发送给你配置的端点。</p>

<p data-lang="en">Use the settings UI to save the endpoint, protocol, models and key. For Responses-compatible endpoints, see the <a href="https://github.com/Infinimesh-ai/InfiniShell-Desktop/blob/main/docs/ai-provider-responses.md">Responses configuration guide</a>.</p>
<p data-lang="zh">通过设置界面保存端点、协议、模型与密钥。使用 Responses 兼容端点时,请参见 <a href="https://github.com/Infinimesh-ai/InfiniShell-Desktop/blob/main/docs/ai-provider-responses.zh-CN.md">Responses 配置指南</a>。</p>

<p class="muted" data-lang="en">Use the model picker to switch models and <code>/</code> to open the slash menu. Cloud Agent, Computer Use, and telemetry ship disabled — see the GitHub repo for the full settings reference.</p>
<p class="muted" data-lang="zh">通过模型选择器切换模型,<code>/</code> 打开 slash 菜单。Cloud Agent、Computer Use 与遥测均默认关闭,完整配置说明请参见 GitHub 仓库。</p>
