# 公共文档与私有证据

[English](README.md) · [文档索引](../README.zh-CN.md)

公共 Git 保存可复用指南、产品与源码身份、公开 CI 链接、必要摘要、限定验收结论和失败边界。本机用户名、真实存储布局、个人配置与数据库细节、私有备份映射及临时调试副本不作为公共操作指南同步。

## private-evidence

`private-evidence:ref-<标识>` 以及带同一标识的“私有证据”链接引用维护者保留的原件。映射保存在不进入 Git 的 `.local/private-evidence-map.json`；它包括原定位符和字段来源；已移出 Git 的旧记录标识也可能保留在映射中。标识由定位符生成，**不是证据文件的 SHA-256**。文中原有 `sha256` 才是原记录的内容摘要。

2026-10-25 整理前，相关文件已逐字节备份并核对 SHA-256；位置记录在 `.local/docs-cleanup-backup.json`。旧 G09、Draft 和一次性平台验收流水已移出 Git，原件和整理中间稿保留本地；不再维护公共历史台账。当前摘要继续保留未验结论及 `cleanup_ready=false`。私有资料移出当前 Git 跟踪不删除既有 Git 历史；本次没有重写历史。

映射存在不证明外部原件仍可访问，也不代表本轮重新核验了原件。需要复核时，请维护者按身份、权限和摘要读取；不要为了修链接上传原始日志、数据库、会话、凭据或截图。
