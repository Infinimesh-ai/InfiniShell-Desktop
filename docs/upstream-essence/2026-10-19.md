## 实施约束

- 文件操作保留本地 watcher；远程 rename 使用未占用的 request 27 / response 48，受保护删除为 28 / 49，恢复为 29 / 50，禁止覆盖的移动撤销使用独立 request 30、复用 rename 回执。不能覆盖现有 ListDirectory 的 22 / 38；旧 daemon 不认识请求时明确失败。TUI 本地删除/移动已有，本轮补远端操作并统一身份和目标快照校验。
- 移动覆盖目标保留原内容及 Unix mode / Windows readonly，用于撤销；预处理不再拆成删除源和写目标。目标在预览后被删除、新建或修改时，在写源文件前失败。Agent 破坏性操作拒绝不能恢复身份的符号链接、reparse point 和多硬链接；普通文件目录项删除仍保留既有语义。
- 删除恢复通过同目录临时文件完整写入、设置权限后以 `persist_noclobber` 发布；移动撤销采用 macOS `RENAME_EXCL`、Linux `RENAME_NOREPLACE`、Windows 不带替换标志的原生移动，拒绝覆盖用户新建的原路径。失败保留重试状态；只有全部恢复完成才将操作标为 Reverted。这里没有承诺 ACL、所有者或扩展属性恢复，也不把跨文件操作称为事务原子操作。
- 远端差异预处理复用现有 ReadFileChunk 25 / 41，保留源文件和目标快照的 CRLF 原始字节，不再经过会归一化换行的 ReadFileContext。维持单文件 10 MB 预算，校验分块偏移、长度、文件大小和 EOF 后统一解码 UTF-8。只有 daemon 明确确认的 NotFound 才表示文件缺失，旧 daemon 的模糊错误及权限错误均中止预处理。回归覆盖真实 daemon 消息处理与预处理、移动、撤销，不能替代真实 SSH 传输验收。
- Bash 同时转义执行路径和 rcfile 内的变量赋值，保留 `$0=bash`；回归通过真实 PTY 执行带空格及单引号路径的 Bash。
- 输入列表按批次有序；历史按首次出现的任务归并，响应关联追加而不覆盖。单任务判定按唯一 task ID，保留同任务多批次的 CLI 模型和 BYOP 目标；压缩恢复继续读取原有序列化结构。
- `new_external()` 复用现有代理配置，不自动添加 InfiniShell/Zap 元信息、追踪、环境附加头或 IAP；调用方显式 API key、路由头和签名参数仍保留。Responses 会话创建、计数和生成均纳入实际 HTTP 回归。
- Claude 受控补丁 rev5→rev6；缺失旧版本字段仍兼容，只有显式空数组表示没有后台任务或 cron，非空及类型异常均保留通知。冻结 rev5 字节摘要供事务迁移，修改过的自定义脚本拒绝覆盖；保留原载荷关联 ID、当前回合正文来源和 Stop→Unknown 规则，不扫描 transcript、不推断 Success、不扩大 CLI 支持版本。
