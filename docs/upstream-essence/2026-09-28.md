- 保留静态凭据拒绝、未解析密钥请求前拦截、loopback OAuth、已有令牌持久化与 headless 行为。SDK 新要求的受保护资源 `resource` 标识已补入测试服务。

### Bash 与补全

- 取消生成器改用完整 PID 数组；测试调用从生产 bootstrap 加载的 `warp_preexec`，只替代无关 OSC 输出，用真实子进程验证两个未完成 PID 均被取消、完成列表和空列表不被误处理。
- ShellCheck 仅检查 Bash bootstrap 的 warning 及以上诊断。保留上游既有目录级 `SC2213/SC2155` 例外；本地 SSH 多层脚本仅局部抑制原有 `SC1083/SC2140`，不改远程引用语义。
- `--` 只有在后续 token 或尾空白确认其输入完成后才结束选项；PowerShell 非 POSIX 签名保持原行为。本地 `v2` 分支与测试隔离保留。

### GUI 生命周期

- `/model` 使用本地现有 `is_window_open` 和动态 `window_id` 做保护；未引入整套 `try_update` 或共享会话 driver。仅取旧候选 [`97037ec83`](https://github.com/warpdotdev/warp/pull/15695) 的测试关窗入口，回归走实际窗口关闭清理。
- 旧候选重新评估的原因是本周期新增 `/model` 活跃用例，并非本地恢复了共享会话。
- 菜单关闭仅在菜单仍持焦点时恢复活动标签，避免覆盖菜单动作已转交给标签/标签组重命名编辑器的焦点。保存标签配置使用有界索引访问。
- 未新增 `TerminalModel::lock()` 或扩大锁范围。

### Vim

- `il` 选取当前行去除两端空格/制表符后的内容；`al` 以行模式覆盖整个缓冲区。复用既有 Vim 模式开关，无须新 feature flag。
- TUI 文本对象使用共享 `motion_type`，段落和全部行对象不再误按字符模式处理。
- 两个 GUI 编辑器为 `al` 及覆盖全部行的 visual 选择使用原文复制路径，保留真实首尾空行；普通命令继续使用原有寄存器处理。
- TUI 行模式先按 Yank 语义复制，再恢复选择执行删除或替换，避免 EOF 删除借用的前置换行污染寄存器；粘贴只消费一个寄存器终止换行。新增删除、替换、粘贴、单次撤销与渲染回归，并覆盖 `yy/dd/Vy`、`yG/Gdgg` 与空行边界。
- 本次没有扩展既有 TUI visual 文本对象的 no-op 分支，不宣称新增完整 visual 文本对象支持。
