# CLI 能力矩阵

本表区分三款 CLI 的接入语义，不宣称全部平台和版本组合均已实测。产品验收基线为 Codex CLI `0.156.1`、Claude Code `2.1.280`、Grok Build `1.0.41`；其他版本是否开放由实际版本/能力门禁决定。更新安装成功不扩大托管兼容范围。

当前发布见[发布入口](../../docs/releases/README.zh-CN.md)，未验项见[当前限制](KNOWN_GAPS.md)。

| 能力 | Codex CLI | Claude Code | Grok Build |
| --- | --- | --- | --- |
| 托管协议 | app-server | 双向结构化流/control | ACP；继承与固定策略分别判断 |
| 文本与上下文 | 多行文本、文件及代码上下文 | 多行文本、文件及代码上下文 | 多行文本、文件及代码上下文 |
| 托管图片 | 原生类型化输入；图片理解另验 | PNG、JPEG、静态 GIF、WebP；纯图及技能组合按固定合同开放 | 固定版本/模型的 Inherit PNG；技能组合要求独占 leader 与目录确认 |
| 普通终端输入 | 文本及本地文件引用；锁定 Shell 模式拒绝文件卡 | 文本及本地文件引用；锁定 Shell 模式拒绝文件卡 | 自动文本/PNG 桥要求已核验定制工件；官方发行版不等同具备该桥 |
| 技能 | 原生 `$` 技能调用 | 原生 Skill；注册确认后发送，热新增与图片组合分别核验 | Inherit 的 local/user 技能与空闲热新增；独占 leader；固定读取/文件策略禁技能 |
| 审批 | 按当前请求允许/拒绝 | 按当前请求允许/拒绝 | 按策略验权；拒绝可能表现为 Cancelled，不能改记成功 |
| 父子任务 | 派发、权限上限、消息及结果回收 | 固定策略下父子链与双向消息 | 固定策略及 SDK 合同下父子链；Inherit 不开放父子工具 |
| 运行中追加 | 活跃回合 Steer | 原生合并或后续轮次 | 后续回合排队，无即时 steer |
| 恢复 | 活跃重关联与历史继续分开 | 同一原生会话与权限合同保持 | 同一会话、技能与策略合同保持 |
| 更新渠道 | latest / alpha | latest / stable | stable / alpha |
| 完成判据 | 可信原生终态及本代监督回执 | 可信原生终态及本代监督回执 | EOF 不能单独判断；以本代监督回执为准 |

## 共同约束

- 应用实例、代次、原生会话/回合及事件来源共同隔离重复、乱序和旧回调；插件文件来源不能替代真实 CLI 身份。
- `native_protocol` ACK 只表示原生接收，`application_history` ACK 只表示写入应用历史；均不证明模型已执行完成。
- 重启不自动重放输入；同一原生会话不并发恢复，恢复失败不偷偷改为新建任务。
- 本地文件卡仅传绝对路径引用，发送前整批核对普通文件及可读性；内容由原生 CLI 按自身审批读取，不保证所有文件格式。
- 通知插件不授予工具权限。插件缺失、禁用、未知来源或不兼容时保留普通终端及失败说明。
- macOS 已有固定组合功能证据；Linux/Windows 完整模型生命周期、输入法及真实审批布局按[当前限制](KNOWN_GAPS.md)保留未验边界。

安装与回退见[支持说明](RELEASE_SUPPORT.md)，升级合同见 [CLI_AUTOUPDATE](CLI_AUTOUPDATE.md)，验证层级见[验证约定](VALIDATION_REPORT.md)。
