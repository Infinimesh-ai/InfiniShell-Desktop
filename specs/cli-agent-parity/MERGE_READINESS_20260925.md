## 合并说明草稿

### 变更说明

InfiniShell 为 Codex CLI、Claude Code 和 Grok Build 提供统一桌面入口与本地托管任务管理，接入各自的结构化协议、审批、持久化、父子消息及恢复。修复固定跳过审批、Claude 启动改写全局配置，以及启动取消时的进程所有权问题；补齐三方通知插件及受支持原生安装的自动升级和渠道选择。Grok 桌面托管入口默认开放，能力仍按实际版本和权限模式判断。

固定受测版本为 Codex `0.156.1`、Claude `2.1.280`、Grok `1.0.41`。这是已有范围的阶段交付，不宣称三款全部能力已对齐、所有安装来源都能自动升级或未来版本天然兼容。完整范围以 [KNOWN_GAPS](KNOWN_GAPS.md) 和 [RELEASE_SUPPORT](RELEASE_SUPPORT.md) 为准。
